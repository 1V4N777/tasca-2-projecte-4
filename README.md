Tasca 2 - Gestió de versions amb Git

Descripció

Aquest repositori forma part de la Tasca 2 i té com a objectiu practicar la gestió de versions amb Git.

Durant aquesta activitat es treballarà amb commits estructurats, consulta de l'historial, recuperació de canvis i gestió de versions anteriors d'un projecte.

Objectius

Crear commits seguint bones pràctiques.

Consultar l'historial del repositori.

Descartar canvis del Working Directory.

Recuperar versions anteriors mitjançant git revert i git reset.
